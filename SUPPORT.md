# Getting help with CIRKS

## Read the documentation first

The [CIRKS documentation](https://wightmanbrown.github.io/cirks/) covers
installing and running CIRKS, loading your organisation, and modelling it well.
Most questions about installation are answered in the
[install guide](docs/INSTALL.md), including its Troubleshooting table.

## Community support (free)

| You want to | Go to |
|---|---|
| Ask a question, share how you use CIRKS, suggest an idea | [Discussions](https://github.com/WightmanBrown/cirks/discussions) |
| Report a bug in CIRKS | [Issues](https://github.com/WightmanBrown/cirks/issues/new/choose), using the bug report form |
| Report a security vulnerability | **Not an issue.** Follow [SECURITY.md](SECURITY.md) |

Community support is given on a best-effort basis, by the maintainers and other
users, with no promised response time.

Please do not put information about your own organisation in a public issue or
discussion: no system names, risks, people or internal addresses. Describe the
problem with the Misty Isles training data or made-up names instead.
